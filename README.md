# Employment — тренажёр лексики

Тренажёр английской лексики по теме Employment (Финансовый университет, Управление персоналом).
Вход через Google (Firebase), прогресс синхронизируется между устройствами.

## Фармакология

Отдельный тренажёр по фармакологии лежит в папке `pharm/` (адрес сайта + `/pharm/`). Тот же вход через Google и тот же Firebase-проект: прогресс хранится в том же документе пользователя в поле `pharm` (запись с `merge`, английский прогресс не затирается).
